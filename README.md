# 裕信汽車｜服專／出納服務量能與人才盤點儀表板

## 開啟方式
- 直接雙擊 `開啟儀表板.bat`（或 `app/index.html`），不需安裝、不需網路。
- 或以本機伺服器：`python -m http.server 5188 --directory app`，瀏覽 http://localhost:5188

## 首頁：戰力總表（專家會同版）
一頁看懂四件事，可直接「列印會議版」：
1. **服務廠戰力排名**：廠戰力＝該廠現行服專＋出納綜合戰力平均（依人數），並列服專／出納平均、高低戰力人數、顧客整體與結帳服務滿意。點列可看該廠人員。
2. **個人戰力全排名**：服專＋出納合併排名（概覽用）與職務內排名，含人才類型、月均量能、顧客問卷滿意、強項／短板。
3. **出納貢獻**：各廠結帳量由誰承接（堆疊圖）、占廠結帳比、1出納對應服專數、電子簽名、感心卡、出納戰力、所屬廠結帳服務滿意。
4. **顧客滿意（人員滿意度問卷）**：整合 [CSI 服務戰情系統](https://maochi710918-gif.github.io/csi-service-dashboard/) 問卷（5分量尺）：各廠五構面、服專問卷排名（≥10份）、顧客文字意見。

問卷資料更新：下載 CSI 系統的 `records.js` 後執行 `node tools/build-csi.js <records.js>`。問卷未記錄出納姓名，出納以「所屬廠結帳服務」呈現。

## 架構（資料與畫面分離、公式集中）
| 檔案 | 用途 |

## 更新資料
1. 系統內：切換身分為「系統管理員」→「資料匯入」→ 上傳相同格式 Excel → 預覽 → 確認匯入（自動重算並保存上期九宮格快照）。
2. 或更新預設檔：`cd tools && npm install && node build-data.js "<Excel路徑>"`，再以 `node verify.js "<Excel路徑>"` 逐欄核對公式。

## 計算口徑（沿用 Excel）
- PR＝同職務「現行」人員中低於本人比例 count(<x)/(n−1)；越少越好指標為 1−該值；構面PR＝構面內指標PR平均。
- 綜合戰力＝Σ權重×構面PR（缺構面按有值權重重配）；服專 30/15/15/10/20/10、出納 35/15/25/10/15。
- 月均＝有值月份平均；單車產值＝業績合計÷接車合計；每100台／張＝次數合計÷台數（張數）×100；資料完整度＝有值欄位÷（欄位數×有效月份）。
- 人員總覽依115.9最新廠別；月度分析依當月實際廠別。空值一律顯示「—」，不以0計算。

## 核對結果（全期、全公司）
系統由月度明細重算 3,642 個總覽欄位，除下列 1 項外與 Excel 完全一致；管理總覽、月度合計、九宮格、服務廠量能共 118 項核對 116 項一致（詳見「資料品質」頁）。

## 需確認事項（Excel 無明文定義，未自行猜測公式）
1. **同年資PR「<1年」群組**：Excel COUNTIFS 以「<1年」為條件時被解讀為比較運算子，母體錯誤（影響 20 人的同年資PR顯示值；不影響戰力、九宮格、升階）。系統依「指標定義」修正。
2. **綜合戰力計分門檻**：Excel 未明文，依現有結果反推「資料完整度 ≥50% 才計分」，已設為可調參數。
3. **人員類型**（核心穩定／量質平衡／高量需改善／品質佳量能未釋放／優先輔導）：Excel 無公式，依「管理建議」首句對應，數字與管理總覽一致。
4. **管理建議文字**為 Excel 原值，選取子期間時不會重新產生。
5. **撫遠鈑噴廠 3 名出納**在115.9名冊中，但無個人量能資料：人數計入、不列入PR／戰力。
6. **同期比較**：目前僅 2026 年資料，顯示「資料未提供」。
7. **KPI 上期**：量能類為「本月 vs 前月」；戰力類為「截至本月 vs 截至前月」重算。
